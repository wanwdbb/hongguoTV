# 红果账号同步接入调查（2026-09-22）

用户目标：用本人抖音账号登录红果，在电视端同步红果收藏、观看历史及续播位置。保持用户只安装 APK、无需自行部署服务。

> 2026-10-24 更新：已按红果官方网页流程接入扫码登录，账号页可以显示账号资料。登录后，「最近观看」「收藏」读取账号中的观看记录与短剧收藏，「预约」读取待上线/已上线预约并支持预约、取消预约。观看进度已接入账号写回，本地收藏仍不写回账号；退出登录后继续使用本机记录。本文下方的 2026-09-22 调查结论保留当时的背景。扫码登录见 [API.md](../kotlin-tv/API.md) 4.6，账号记录接口见 4.7。

## 2026-09-22 调查结论

该轮没有实现红果登录或云端同步。缺少经过验证的红果用户授权、账号映射、收藏和进度读写接口；普通抖音 OAuth 授权不能作为这些权限已获授予的证据。不得将头像或昵称获取成功标记为“红果已登录/已同步”。

- 当前客户端 `ContentRepository` 使用游客内容请求，搜索参数 `user_is_login=0`；`Library` 的收藏和进度在本机 SharedPreferences，没有平台账户会话。
- 检查红果官网首页、首页直接引用的三个业务脚本，未找到登录入口或账户同步实现。范围仅限这些公开资源，不能据此推断平台没有内部或合作接口。
- [抖音 SDK 概述](https://open.douyin.com/platform/resource/docs/develop/summarize/sdk) 描述抖音授权和获取公开用户资料；更多数据能力需对应申请。未找到明确开放红果收藏和观看进度的 scope。
- [抖音网站 OAuth 文档](https://open.douyin.com/platform/resource/docs/develop/permission/web/oauth2) 要求注册开发者配置 ClientKey / ClientSecret，通过授权码交换令牌，并提示应用密钥放在客户端不安全。项目当前未配置该应用的平台注册凭据，不能挪用红果官方 App 的身份和应用密钥来声称已授权。
- 该轮没有收集用户密码、验证码、Cookie 或令牌，没有登录或改动用户的平台收藏和进度。

## 接通所需证据

1. 平台允许此应用使用的授权方式、ClientKey、应用包名/签名配置，以及是否必须有服务端保管应用密钥。只有可安全运行于客户端的授权流才能直接保持纯 APK；服务端必需时必须另行明确托管方案，不能将密钥塞入 APK。
2. 抖音身份到红果账户的受支持映射及用户数据授权范围。
3. 收藏分页、历史与精确播放进度读取接口，含字段定义、权限错误及会话过期行为。
4. 先完成本人真实账号只读验证，再接入收藏和进度写回。双端冲突按更新时间与明确的播放会话处理；不能简单取最大集数，避免覆盖用户重新观看较早集的意图。
5. 退出、过期、换号测试；按平台账号隔离缓存，保留并区分既有本地游客记录，避免串号。

目前已经接入的只读账号记录、预约与取消预约基于官方网页/客户端实际观察到的接口；观看记录写回采用抓包中实际出现的 read_history/update/v 接口；账号隔离、持久化待同步队列和较新云端记录冲突检查已接入，同源 Pets 测试版已完成云端回读：剧集一致、位置差 0ms、待同步 0；卸载重装后的正式版需重新登录，实体设备跨端与长时间离线仍需验收。账号页的二维码走红果官方网页扫码登录；新版本中的“手机输入”二维码仅发送局域网搜索词，“版本与更新”二维码仅打开 GitHub Release 页面，都不是红果账号登录。
